The bet

System One: Jev

Makes typed decisions on every complaint in well under a second: which product it's about, how severe it is, whether the customer may be vulnerable, whether the text is trying to manipulate an AI. It returns probabilities, not prose, so software can act on them.

System Two: LLM agents

Investigate, compare with similar past cases and draft replies. They only see the cases System One escalates, and their drafts are checked before a person sees them.

The vendor's confidence score shows how concentrated its probabilities are. It is not a promise of accuracy. So ConductOS measures accuracy against real labels, recalibrates, and lets an agent act alone only when the lower bound of a 95% confidence interval clears the target.

How autonomy is earned

  1. Suggest. The agent proposes; a person decides every case.
  2. Act with approval. The agent prepares the action; it runs after a person approves.
  3. Act and notify. Reversible actions run, then a person is told and can undo.
  4. Autonomous. Runs within limits; people audit samples and metrics.

Each action type climbs separately, with evidence and sign-off from the compliance lead. It drops automatically when reviewers start overriding it or calibration drifts. Sending a substantive reply to a customer is capped at "act with approval". Filing a regulatory report never runs without a person.

How it's built

One product, three platform pillars, each a folder in one repository.

Agentic gateway

One door for every model call: personal-data redaction, a fallback chain from Jev to keyword rules, a kill switch, and a trace of cost, latency and model version for each decision.

Shows: platform and API design, cost and latency trade-offs, vendor hedging.

Gateway code

Operations pod

Specialised agents that pass typed contracts, never free text. A state machine blocks illegal steps in code. A supervisor applies the autonomy policy without asking any model what to do.

Shows: agent orchestration, state machines, human-in-the-loop design.

Pod code

Evaluation harness

Reliability diagrams, calibration error, out-of-fold recalibration and thresholds chosen on confidence bounds, benchmarked against a keyword baseline the AI has to beat.

Shows: statistical rigour with non-deterministic AI, release gating.

Roadmap

  1. Prove the decision layer. Calibration on live complaints against a keyword baseline. In progress
  2. Governed autonomy. Review queue, automatic promotion and demotion, tracing and quotas.
  3. Hard cases. LLM investigation and drafting with verifiers; emerging-issue alerts for compliance.
  4. Platform reuse. Anti-money-laundering alert investigation on the same three pillars.
